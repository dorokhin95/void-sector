# VOID SECTOR — Орбита забвения

Космический 3D-шутер прямо в браузере на чистом WebGL, без сборки и внешних
ресурсов: модели, текстуры, взрывы, звук и музыка синтезируются программно.
Кампания на 20 уровней (4 акта, 4 босса, ангар и прокачка), бесконечный режим,
15 классов врагов и русский сюжет с диалогами в эфире прямо во время боя.

**[▶ Играть](./index.html)** — страница выбора версии (ПК или телефон).

## Версии

| Папка | Для чего |
|---|---|
| [`VOID-SECTOR/`](VOID-SECTOR) | ПК: клавиатура (WASD), мышь, полноэкранный режим |
| [`VOID-SECTOR-MOBILE/`](VOID-SECTOR-MOBILE) | Телефон: два виртуальных джойстика, вибро-отклик, работает как обычный сайт, PWA (добавление на экран «Домой») и как **Telegram Mini App** |

Обе версии — статические файлы, открываются прямо из `index.html`, сервер и
сборка не нужны.

## Запуск локально

Любой статический веб-сервер подойдёт, например:

```bash
npx serve VOID-SECTOR          # ПК-версия на http://localhost:3000
npx serve VOID-SECTOR-MOBILE   # мобильная версия
```

## Публикация на GitHub Pages

Репозиторий уже готов к раздаче как статический сайт: достаточно включить
**Settings → Pages → Deploy from a branch → `main` / `/ (root)`**. Ссылка на
корневую `index.html` появится вида `https://<аккаунт>.github.io/<репозиторий>/`.

## Публикация как Telegram Mini App

`VOID-SECTOR-MOBILE` уже содержит официальный SDK
(`telegram-web-app.js`) и автоматически определяет запуск внутри Telegram —
включает полноэкранный режим, блокирует альбомную ориентацию, отключает
свайп-закрытие (чтобы не мешать джойстикам) и подключает аппаратную кнопку
«назад». Вне Telegram эти файлы не мешают обычной работе сайта.

Чтобы подключить бота:

1. Открой [@BotFather](https://t.me/BotFather) в Telegram, `/newbot` (если бота
   ещё нет) или выбери существующего.
2. `/mybots` → выбери бота → **Bot Settings → Menu Button → Configure Menu
   Button** → укажи URL страницы `VOID-SECTOR-MOBILE` (после публикации на
   Pages это будет `https://<аккаунт>.github.io/<репозиторий>/VOID-SECTOR-MOBILE/`).
3. Либо `/newapp`, чтобы создать полноценное Mini App с отдельной карточкой —
   там же указывается тот же URL.

Ссылка должна быть по HTTPS — GitHub Pages это обеспечивает автоматически.
