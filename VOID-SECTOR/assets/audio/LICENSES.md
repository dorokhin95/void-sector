# Сторонние аудио-сэмплы — провенанс

Все файлы в `assets/audio/sfx/` — из паков **Kenney** (kenney.nl), лицензия
**CC0 (Creative Commons Zero)**: http://creativecommons.org/publicdomain/zero/1.0/
Свободно для личного, образовательного и коммерческого использования,
атрибуция не обязательна (но Kenney её ценит — потому этот файл и существует).

Используются только как короткие **transient/body** сэмплы, наложенные
поверх уже существующего процедурного синтеза (см. `audio.js`) —
процедурный слой остаётся основным источником суб-баса, sci-fi
энергетических тонов, pitch-движения и «хвостов»; сэмплы дают физическую
достоверность удару/взрыву/выстрелу, которую чистая синтетика не даёт.

## Источник

- **Пак:** Sci-Fi Sounds (1.0)
- **Автор:** Kenney (www.kenney.nl)
- **Страница:** https://kenney.nl/assets/sci-fi-sounds
- **Файл:** `kenney_sci-fi-sounds.zip`
- **Лицензия:** CC0 1.0 (см. `License.txt` внутри пака)
- **Дата загрузки:** 2026-09-09
- **Изменено:** да — конвертировано из `.ogg` в mono MP3 32kHz 64kbps
  (`loudnorm` для ровной громкости); `thrusterFire_*` дополнительно
  обрезаны до ~0.45с (из оригинальных 5с loop-эмбиента, чтобы получить
  короткий «ignition pop», а не длинный гул двигателя) и зафейжены на выходе.
